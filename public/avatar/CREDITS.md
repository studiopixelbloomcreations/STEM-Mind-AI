# Official STEM avatar

`stem.glb` is **RobotExpressive**, downloaded from the official three.js examples:

https://three.js.org/examples/models/gltf/RobotExpressive/RobotExpressive.glb

Originally published with the Khronos glTF Sample Models / three.js example set.
Used here as the official classroom mascot **Stem**.

`stem-alt.glb` is a stylized low-poly humanoid robot (purple accents) downloaded from Get3DModels as a backup look.
